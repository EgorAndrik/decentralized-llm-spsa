# Набор для проверки маршрутизации

В наборе 1000 заданий. В каждой строке таблицы поровну лёгких и сложных задач.

| Категория | Лёгкие | Сложные | Всего |
| --- | ---: | ---: | ---: |
| Алгоритмы и Python | 167 | 167 | 334 |
| Написание текстов | 167 | 167 | 334 |
| Математика | 166 | 166 | 332 |
| Всего | 500 | 500 | 1000 |

В `tasks.jsonl` у каждой задачи есть `id`, `category`, `difficulty`, `prompt`,
`expected`, `language` и `source`. У новых записей есть `source_id`; у
синтетических вариантов есть `family`. Поле `expected` предназначено
для сверки результата. MBPP дополнительно содержит исходные проверочные
выражения `reference_tests`, GSM8K — числовой `reference_answer`, IFEval —
структурированные ограничения `reference_checks`.

`prompts.txt` содержит только условия, по одному на строку, в том же порядке,
что и в JSONL. Категории и сложности чередуются. Первые 30 строк — исходные
задания. Для пробного запуска через `--warmup-file` флаг `--tasks` ограничит
число загруженных строк.

## Происхождение

- **30 исходных и 483 синтетических задания на русском.** Синтетические
  задания включают варианты с разными массивами, числами и сценариями.
  Задания с одинаковым `family` относятся к одному шаблону.
- **162 задачи MBPP на английском.** Исходное условие дополнено именем
  функции, пробельные символы нормализованы. Номер в `source_id` совпадает
  с `task_id` источника. [Данные MBPP](https://github.com/google-research/google-research/blob/bb18d9b0cb460fee1a080fa2eeb4109fe3805275/mbpp/mbpp.jsonl).
- **164 задачи IFEval на английском.** Нормализованы пробельные символы,
  сохранены идентификаторы и аргументы проверяемых ограничений. Номер в
  `source_id` совпадает с `key` источника. [Данные IFEval](https://github.com/google-research/google-research/blob/bb18d9b0cb460fee1a080fa2eeb4109fe3805275/instruction_following_eval/data/input_data.jsonl).
- **161 задача GSM8K на английском.** Взяты многошаговые задачи из тестовой
  части, сохранены числовые ответы и решения, нормализованы пробельные
  символы. Номер в `source_id` — номер строки исходного файла, начиная с 1.
  [Данные GSM8K](https://github.com/openai/grade-school-math/blob/3101c7d5072418e28b9008a6636bde82a006892c/grade_school_math/data/test.jsonl).

[Лицензия MBPP и IFEval (Apache-2.0)](LICENSE-GOOGLE-RESEARCH.txt).
[Лицензия GSM8K (MIT)](LICENSE-GSM8K.txt).

Сложность размечена эвристически. Например, в IFEval у лёгких заданий
одно проверяемое ограничение, у сложных — несколько. Метки пока не
калиброваны прогонами моделей. Исходные эталоны из открытых наборов
сохранены для проверки при оценке ответов. Для сравнения качества
по категориям стоит учитывать язык и происхождение задания.
